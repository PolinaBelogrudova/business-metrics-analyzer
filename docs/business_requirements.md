# Бизнес-требования к учебному приложению «Business Metrics Analyzer»

## 1. Назначение приложения
Экспресс-анализ KPI малого предприятия на основе данных о выручке и затратах за месяц.

## 2. Целевая аудитория
- Руководители и владельцы малого бизнеса;
- Аналитики без навыков программирования.

## 3. Функциональные требования
- FR-1. Хранение исходных данных: месяц, выручка, затраты.
- FR-2. Расчёт прибыли за каждый месяц.
- FR-3. Расчёт рентабельности в процентах.
- FR-4. Вывод сводной таблицы и средней выручки.
- FR-5. Перспектива: график метрик и загрузка данных из CSV/XLSX.

## 4. Нефункциональные требования
- NFR-1. Python 3.10+, библиотека pandas.
- NFR-2. Запуск одной командой `python main.py`.
- NFR-3. Человекочитаемый вывод в консоль.
- NFR-4. Документация проекта (docstring, README, docs/).

## 5. Ограничения
- Учебная версия работает на встроенных данных.
- Консольный интерфейс, без веб-части.
