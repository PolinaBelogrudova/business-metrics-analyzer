# Контрольные вопросы

## 1. Чем отличается Git от GitHub?
Git — локальная система контроля версий на компьютере разработчика.
GitHub — облачный сервис для хранения репозиториев и командной работы.

## 2. Для чего используется виртуальное окружение Python?
Для изоляции зависимостей проекта, чтобы не смешивать пакеты разных проектов.

## 3. Что такое commit, branch, remote, pull request?
- commit — фиксация изменений в истории;
- branch — независимая линия разработки;
- remote — удалённый репозиторий;
- pull request — запрос на слияние с код-ревью.

## 4. Зачем нужен .gitignore?
Чтобы не загружать в репозиторий служебные файлы: .venv/, __pycache__/, *.pyc, .env.

## 5. Как организовать командную работу через Git?
Каждый ведёт feature-ветку, делает PR, проходит ревью, изменения сливаются в main.

## 6. Обязательные файлы в учебном проекте?
README.md, .gitignore, main.py, requirements.txt.

## 7. Что будет при изменении одного файла в разных ветках?
Возникнет merge conflict, который решается вручную.
